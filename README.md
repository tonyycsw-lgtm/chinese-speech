# 中文朗誦練習（Chinese Speech Practice）

為學生設計的中文朗誦練習網頁，支援弱視學生（無障礙模式）。

## 頁面

- `index_P4.html` — 作品：《聽雪》（金波），14 句，配 4 種音色＋整首朗誦
- `index_S2.html` — 作品：《水仙子・尋梅》（喬吉）＋《春夜喜雨》（杜甫），共 16 句

## 功能

- 作品／音色大按鈕選擇（循環切換：男聲 A → 男聲 B → 女聲 A → 朗誦）
- 逐句朗讀、上句／下句、語速調節
- 錄音：按住錄音、放開播放；錄音中顯示音量柱，播放錄音顯示聲波浪紋
- 無障礙模式：黑底大字、高對比按鈕，適合弱視學生

## 音檔

- `sound/聽雪/`、`sound/水仙子-寻梅/`、`sound/春夜喜雨/`（每句一句，多種音色）
- `00-朗誦.mp3` 為整首朗誦音檔
